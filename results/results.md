# Results Directory

This folder contains the raw output data for the paper
[arXiv:2609.28084](https://arxiv.org/abs/2609.28084).

- **Code version**: `419fe93` (commit hash)

All experiments were conducted on a machine equipped with a 3.10 GHz 8-core Intel Core i9-9900 processor and 64 GB of RAM. We used Gurobi 13.0.1 as the solver.

## Correspondence with the paper

| File | Paper |
| --- | --- |
| `MILP_vs_Benders_main_results.csv` | Section 5.2, Table 1 and Table EC.2: `OD+MILP` versus `OD+B&BC` |
| `bigM_ablation_results.csv` | Section 5.3, Table 2: interdiction-cut coefficients (No-good and Critical; the Global rows are not reported) |
| `LP_benders_results.csv`, `closed_form_benders_results.csv` | Section 5.4, Table 3: LP-based versus closed-form Benders separation |
| `scalability_results.csv` | Section 5.5, Table 4: scalability with respect to the customer dimension |
| `dual_degeneracy_results.csv` | Section EC.5.1, Table EC.3: dual-degeneracy cuts |
| `sensitivity_beta_b_results.csv` | Section EC.5.3, Table EC.5: sensitivity to the target fraction and the follower budget |
| `critical_tie_results.csv`, `fractional_separation_results.csv`, `sensitivity_beta_b_results_equal_cardinality.csv` | Additional diagnostics not reported in the paper |

The column `vf_cuts` is the number of interdiction cuts generated by the outer
decomposition.
